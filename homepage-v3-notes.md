# Главная v3 — матовые поверхности

По замечанию пользователя белая подложка заголовка заменена на полупрозрачную зеленовато-молочную поверхность: 24% фона, backdrop blur 14px, тонкий светлый край, мягкая тень. Водный фон просвечивает; текст остаётся непрозрачным.

Шапка размещена поверх того же водного фона в округлой полупрозрачной плашке: 38% фона, blur 18px, радиус 999px. Первый экран получил верхний отступ под шапку. Мобильные значения заданы отдельно. При отсутствии поддержки backdrop-filter предусмотрена более плотная подложка для читаемости.

Портрет, палитра, шрифты и секции ниже первого экрана сохранены. v2 сохранена отдельно. Это точечная правка CSS основным агентом, без отдельного запуска генерации. Визуальная проверка браузером не выполнена; требуется совместный просмотр.
