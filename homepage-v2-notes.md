# Homepage v2 — решения и ограничения

## Что изменено по обратной связи

- Сохранён исходный `homepage-draft.html`; v2 зарегистрирован отдельным `homepage-v2.html.artifact.json` с entry `homepage-v2.html`.
- Hero переведён в внешний полноширинный `.hero-bleed` с локальным `assets/backgrounds/quiet-water-light-v1.png`. Фон виден как существенная подложка всей первой секции: слева остаётся спокойная молочная зона для текста, справа — водные блики и портрет.
- Внутренняя `shell` сохранена только для контента, поэтому фон больше не ограничен узким контейнером.
- Дизайн радиусов обновлён: controls — pill `999px`, program/note cards — `32px`, крупная hero-панель — `48px`; старый control radius `8px` удалён.
- Группа фактов эксперта стала мягкой округлой композицией с отдельными округлыми ячейками вместо квадратной таблицы.
- Quote на Lora Italic встроена в собственную светлую matte-плашку с `min-width:0`, нормальным переносом и `font-style:italic`. На desktop допускается контролируемая связь с портретом, на мобильном quote находится в обычном потоке после изображения.
- Внутреннее название направления «Тихая вода» убрано из интерфейса; в hero используется только фактическое «Личное сопровождение».

## Responsive decisions

- 390px: вертикальная композиция, портрет и quote не пересекаются; CTA остаётся доступным сразу после описания.
- 768px: hero сохраняет асимметрию, но quote уже не может выйти за свою карточку; сетки переходят к tablet/desktop только через `min-width:760px`.
- 1280/1440px: полноширинный фон остаётся за пределами shell, текст и фото размещены в двух колонках без горизонтального overflow.
- Портрет отображается в соотношении исходника `1122 / 1402` с `object-fit:cover` и `object-position:center top`, поэтому сохраняются голова, лицо и естественные пропорции.

## Неизменённые факты и ограничения

- Сохранены утверждённые цвета, три локальные шрифтовые роли, цены/сроки, описание сопровождения и все якоря.
- Для «Голодание 7/7» и «Голодание 14/14» ₽/$ по-прежнему не выдуманы: указано «уточняются».
- Telegram URL неизвестен. Все CTA ведут на `#telegram` и показывают только preview-уведомление «Ссылка на бот будет добавлена перед запуском».
- Не добавлялись отзывы, сертификаты, гарантии лечения, медицинский перечень противопоказаний, контакты, юридические тексты и ссылки на оплату.
- Новые фото, 3D и генерация не использовались. Фон и портрет — локальные PNG из проекта.

## Проверка

- Статически проверены: локальные пути изображений и шрифтов, отсутствие hotlinks/placeholders, только шесть утверждённых цветовых literals, корректные HTML/script closing tags, наличие `prefers-reduced-motion`, якорей и Telegram preview handler.
- Detector доступен только в degraded regex fallback из-за отсутствующих parser-модулей; единственное advisory — частота длинного тире в русском тексте.
- Ранее bundled renderer падал с кодом завершения 134 без диагностического вывода. Повторно не запускался, чтобы не создавать дорогой/неинформативный цикл. Визуальная проверка в этом запуске не заявляется как выполненная.
