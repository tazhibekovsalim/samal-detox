# Homepage draft — принятые решения

## Что собрано

- Первый reviewable-вариант главной страницы Samal Detox в `homepage-draft.html`.
- Mobile-first композиция с самостоятельным первым экраном для ширины 390px и расширением до desktop 1440px.
- Основной путь: сайт → Telegram-бот → разговор → выбор программы → чек ограничений → оплата в боте.
- Четыре сопоставимые карточки программ с подтверждёнными сроками и ценами.
- Отдельные блоки об эксперте, пути знакомства и необходимости учитывать ограничения/противопоказания.

## Визуальные решения

- Утверждённая «Тихая вода»: тёплый молочный фон, зелёные чернила, основной зелёно-голубой, эвкалипт, дымка и песок.
- Hero построен на вертикальном утверждённом портрете с полной видимой зоной лица. Округлая фотозона и мягкая асимметрия создают глубину без прямоугольной маски и без текста поверх лица.
- Cormorant Garamond Italic используется только для крупных эмоциональных акцентов.
- IBM Plex Sans Local используется для прямого текста, UI, цен и прямых заголовков.
- Lora Italic оставлен для одной короткой личной цитаты в hero. Два курсивных семейства не смешиваются в одной строке или абзаце.
- Анимация ограничена появлением интерактивного статуса Telegram и лёгкими hover/focus-состояниями; основной контент доступен без JS.

## Честные ограничения draft

- Telegram URL пока не предоставлен: все Telegram CTA остаются якорями на секцию `#telegram` и показывают только preview-сообщение «Ссылка на бот будет добавлена перед запуском». Фиктивный переход или чужой бот не используются.
- Для «Голодание 7/7» и «Голодание 14/14» в брифе подтверждены только цены в ₸. Значения ₽/$ не выдуманы и помечены как уточняемые.
- Не добавлялись отзывы, проценты успеха, гарантии лечения, сертификаты, дополнительные контакты, ссылки на оплату, полный FAQ, юридические тексты и лид-магнит.
- Текст о противопоказаниях намеренно общий: подтверждённого медицинского перечня в проекте нет. Для production потребуется согласованный дисклеймер и юридические тексты.
- Портрет имеет происхождение встроенной генерации и не выдаётся за документальную фотографию практики.
- Это композиционный draft для совместного просмотра, а не финальная медицинская/юридическая версия сайта.

## Проверки

- Портрет: локальный PNG, исходный размер 1122×1402, `width`/`height` заданы, `object-fit: contain` сохраняет полный утверждённый кадр и ключевую зону лица.
- Шрифты: используются локальные `cormorant-garamond.ttf`, `ibm-plex-sans.ttf`, `lora-italic.ttf`; подтверждённая кириллица, казахские символы и валютные знаки сохранены.
- В интерактивном preview CTA не сообщает об успешном переходе и не ведёт на внешний URL.
